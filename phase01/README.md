# ROJBEY Phase 01 — Google Sheets + Apps Script

حزمة تنفيذ على نفس Spreadsheet المرتبط بمشروع Apps Script، وليس على JSON أو بيانات mock. **لم تُنشر ولم تُختبر على شيت العميل بعد.** تقرير الفجوات كُتب قبل تعديل المصدر: [التدقيق](docs/AUDIT.md).

## الموجود في الحزمة

- `Code.gs`: الدوال الأصلية المتوافقة، تعديل عميلة/موعد، المتابعات، Dashboard، سجل العمليات والتعافي من الطلبات المعلقة.
- `Workbook.gs`: خريطة صريحة للنسخة المفحوصة، تعيد استخدام القوائم الحالية وتحافظ على الأسماء التاريخية.
- `Schema.gs`: أسماء الأعمدة الأصلية، الربط بالمعرّفات، التحقق، وصلاحيات المستخدمين.
- `Setup.gs`: تدقيق للقراءة فقط، نسخ احتياطي مع تحقق، تجهيز محافظ، وقوائم Google Sheets.
- `Index.html`: Web App وSidebar يعملان عبر `google.script.run` فقط، بدون أي بيانات مضمنة أو fallback.
- `appsscript.json`: Runtime V8 وتوقيت القاهرة وصلاحيات Google المطلوبة.
- [قاموس البيانات](docs/DATA_DICTIONARY.md)، [الرحلة والقوائم](docs/WORKFLOW.md)، [النشر](docs/DEPLOYMENT.md)، [النسخ والاستعادة](docs/BACKUP.md)، [الاختبارات والحالة](docs/TEST_REPORT.md).

المصدر التاريخي محفوظ دون تغيير في `docs/skills/rojbey-crm/references/Code.gs`. تطبيق Next.js على Render مشروع عرض سابق، ولم يتم ربطه أو توسيعه في هذه المهمة.

فُحصت نسخة Excel الفعلية: **1465 عميلة، 19 عمودًا أصليًا**. تفاصيل الجودة والتكييف وحدود التحقق في [تدقيق النسخة](docs/WORKBOOK_AUDIT.md). اعتماد الموظفات مؤجل بطلب المستخدم؛ لم يُغيّر الشيت الحي.

## البداية الآمنة

ابدئي **بنسخة اختبار منفصلة** من الشيت، وليس الملف التشغيلي. احفظي نسخة المشروع القديم بكل ملفاته قبل تركيب المصدر. اتبعي `docs/DEPLOYMENT.md`: ربط → تدقيق بدون كتابة → مطابقة الأعمدة → نسخة احتياطية متحقق منها → تجهيز → مراجعة القوائم → اختبارات Google الحية.

`RB_setup` يتوقف إذا وجد مخططًا غير متوافق، تبويبًا مكافئًا محتملًا، توقيتًا مختلفًا مع بيانات قائمة، أو نسخة احتياطية غير مطابقة. لا يقوم بمسح أو ترحيل أو dedup للسجلات القديمة. نجاحه لا يثبت ظهور القوائم فعليًا ولا اكتمال التهيئة التجارية؛ افحصي نتيجة `needsConfiguration` والقوائم في الشيت.

## حدود مهمة

- الدوال الجديدة تحفظ نفس أعمدة المصدر وتستخدم أسماءها، وتحافظ على الأعمدة الإضافية والصيغ. تُضاف `Last Request ID` إلى الجداول التشغيلية و`Request ID` إلى سجل العمليات بعد النسخ الاحتياطي.
- بيانات التاريخ الجديدة للأيام والوقت نص ISO وHH:mm؛ timestamps هي قيم Date. التاريخ الأصلي للفرح يبقى كما هو؛ لا نخمّن بيانات تاريخية ناقصة.
- مقارنة الهاتف تنقل الأرقام العربية/الفارسية إلى أرقام موحدة وتزيل الفواصل؛ تحفظ قيمة العرض وتحوّل `00` إلى `+` للمقارنة فقط. لا نضيف كود بلد مفترض. السجل المكرر لا يندمج تلقائيًا.
- المواعيد تمنع نفس الموظفة أو العميلة من حجز نفس اليوم ووقت البداية، وتستثني الملغي. **لا يوجد تحقق تداخل مدد**؛ المصدر لا يحدد مدة جلسة أو ساعات عمل أو buffers.
- `ScriptLock` يسلسل الدوال في **هذا المشروع فقط**. لا يمنع تحرير المستخدم المباشر لخلايا Sheets أو الكتابة من مشروع آخر. استخدمي Sidebar/الواجهة للعمليات التي تحتاج ID وتاريخ تعديل وتسجيلًا موثوقًا. التعديل اليدوي المباشر ليس مسارًا مُدقّقًا تلقائيًا؛ لا توجد onEdit triggers مخفية.
- جميع استدعاءات البيانات تتطلب بريد Google ظاهرًا ومسموحًا. النشر يجب أن ينفّذ بهوية المستخدم الذي يصل للتطبيق؛ لا تعتمدي على صفحة عامة تعمل بهوية المالك. صلاحيات الملف الأساسية تبقى صلاحيات Google Sheets، وليست row-level permissions.
- لا توجد مبيعات/إيجارات/مدفوعات/توافر فساتين أو تشغيل Meta أو رسائل آلية. هذه متوقفة على مخطط المصدر وقواعد أعمال مؤكدة.
- لا تُنشأ triggers أو اتصالات خارجية أو إشعارات. `RB_audit` يقرأ triggers التي يراها حسابه فقط؛ لا يثبت غياب triggers أنشأها مستخدم آخر.

## الاختبارات المحلية

من جذر المستودع بعد `npm ci`:

```bash
node --test phase01/tests/*.test.cjs
```

يتطلب اختبار الواجهة Chromium في `/usr/bin/chromium` أو `CHROMIUM_PATH`. اختبارات `.gs` تستخدم test doubles لخدمات Google. اختبارات Chromium تستخدم الواجهة الفعلية مع **جسر Google مُحاكى** إلى نفس ملفات `.gs`. هذه اختبارات محلية، وليست دليل قراءة/كتابة على Google أو دليل صحة ظهور dropdowns في تطبيق Google Sheets.

## جسر Render الاختياري

طلب المستخدم ربط نسخة Render بنفس الشيت. أضيف Bridge.gs ضمن هذا النطاق، وهو مغلق افتراضيًا. تفاصيل النشر بهوية المالك وحدود التوقيع في [دليل الجسر](../docs/RENDER_SHEETS.md). وضع الجسر يوقف GET الخاص بواجهة Web App العامة؛ Sidebar يظل داخل الشيت. لا تنطبق تعليمات user-accessing للواجهة القديمة على الجسر الموقّع. الكود المجمع يتضمن Bridge.gs بالفعل، ولا يُثبت تفعيلًا حيًا.
