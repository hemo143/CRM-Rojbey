- الهاتف نص: 355 قيمة مفقودة، و4 قيم لا تطابق الشكل المقبول بعد التطبيع، و156 مجموعة تكرار تشمل 343 سجلًا. لا دمج ولا تصحيح تلقائي.
- المصدر مفقود في 927 سجلًا؛ توجد 101 قيمة تاريخية مختلفة غير فارغة، بعضها نص حر. لا تحويل تلقائي إلى قائمة الخيارات.
- عمود الموظفة يحتوي 166 قيمة تاريخية مختلفة؛ ليست قائمة موظفات معتمدة. **طلب المستخدم تأجيل اعتماد القائمة**؛ القيم القديمة محفوظة ولا تُنسخ إلى قائمة الإسناد.

- وجود خيارات لحالة الدفع والفستان لا يثبت وجود دفعات أو مخزون أو قواعد مالية؛ لا تنفيذ مالي مفترض.

## التكييف المنفذ

يُشغّل `RB_configureObservedWorkbook` بعد الربط للتحقق من العناوين وحفظ خريطة في Script Properties فقط، دون تغيير الخلايا. يعيد استخدام «القوائم والإعدادات» وأعمدته العشرة؛ لا ينشئ كتالوجًا موازيًا. بعد نسخة احتياطية متحققة، يضيف التجهيز عمود «الموظفات» فارغًا، وLast Request ID كعمود العميلات العشرين، وبيانات التشغيل الداخلية. لا يُعتمد اسم موظفة تاريخي تلقائيًا. الإسناد الجديد يتطلب قائمة معتمدة لاحقًا، ويمكن الاحتفاظ بإسناد قديم دون تغييره.

نوع الموعد الافتراضي «زيارة أولى» من القائمة الموجودة. «ملغاة» تستبعد المتابعة من المستحق والمفتوح وتمنع إكمالها. أعمدة التواصل الخمسة مدعومة في الملف الشخصي دون ربط Meta أو إرسال رسائل.

## التحقق وحدوده

شُغّل المصدر على نسخة خاصة من جميع السجلات الـ1465 عبر خدمات Google محاكاة. تطابقت بصمات كل خلايا الأعمدة الأصلية الـ19 وكل أعمدة الكتالوج الـ10 قبل الربط والتجهيز وبعدهما؛ لم يحدث دمج أو اختلاق تواريخ. البيانات الخاصة خارج المستودع فقط. هذا لا يثبت Google OAuth أو النسخ الاحتياطي الحقيقي أو ظهور dropdowns أو سلامة النشر الحي.

التالي على نسخة Google خاصة: حفظ مصدر Apps Script الحالي → تركيب الملفات → `RB_bindSpreadsheet` → `RB_configureObservedWorkbook` → `RB_audit` → `RB_createBackup` والتحقق → `RB_setup` → مراجعة النتائج واختبارات Google. اعتماد الموظفات مؤجل. راجع [تعليمات التركيب](DEPLOYMENT.md).

لإعادة التدقيق محليًا يلزم Python وopenpyxl. الأداة `tools/audit_xlsx.py` تُخرج إحصاءات فقط، ويمكن إنشاء snapshot خاص خارج Git ثم اختباره باستخدام `tools/verify_snapshot.cjs`. لا ترفع XLSX أو snapshot إلى المستودع.
