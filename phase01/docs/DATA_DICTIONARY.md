# قاموس البيانات — المصدر المتاح، وليس تدقيقًا للشيت الحي

الإصدار يحافظ على أعمدة Code.gs الأصلية وأسمائها ويبحث عنها بالاسم، ولو تغيّر ترتيبها. لا يحذف أعمدة إضافية ولا يبدّل الصيغ. الأعمدة الإضافية غير المعروفة غير مُعرّفة هنا حتى يُفحص الملف الفعلي. الصف الأول للعناوين؛ صف البيانات ليس معرّفًا دائمًا.

## العلاقات والمعنى

- Customer ID هو مرجع المواعيد والمتابعات؛ الأسماء المنسوخة في سجلات الزيارات للتوضيح وليست مفتاح العلاقة.
- لا تُولد معرفات لكل صف تاريخي تلقائيًا. اعتماد صف بلا ID عملية صريحة من القائمة؛ لا تُخترع له creation date.
- `Last Request ID` + سجل الطلبات + Request ID في سجل العمليات تربط الكتابة باستعادتها وتمنع إعادة التنفيذ. لا تستعملي رقم الصف للمزامنة أو النقل إلى قاعدة بيانات.
- تاريخ/وقت التشغيل بتوقيت Africa/Cairo. الصف ذو تاريخ محلي غير معروف يظل محفوظًا ويظهر تحذير بدل إدخاله في حسابات مبنية على تخمين.
- التاريخ في سجل العمليات قيمة Date؛ يعود للواجهة ISO string لتفادي نقل Date غير مدعوم عبر google.script.run. كل القيم العائدة للواجهة strings/numbers/booleans/arrays/objects قابلة للتسلسل.
- عمليات transaction/payment/dress inventory ليست لها جداول في هذا الإصدار؛ لا توجد أرصدة أو عملة أو availability مفترضة.
- قواعد الإعداد والقوائم ومرادفات الحالات موضحة في WORKFLOW.md؛ أسماء Named Ranges ثابتة وتتطلب فحص collision قبل استخدامها.


## تحديث النسخة الفعلية — 2026-10-24

راجع [تدقيق Excel](WORKBOOK_AUDIT.md) للمخطط المفحوص. أعمدة التواصل الخمسة الأصلية مدعومة، وكتالوج «القوائم والإعدادات» الحالي يُستخدم عبر خريطة Workbook.gs. عمود الموظفات المعتمد يُضاف فارغًا؛ اعتماده مؤجل، والقيم التاريخية محفوظة. حالة المتابعة الملغاة تُستبعد من المستحق؛ إعداد taskCancelled اختياري في المخطط العام وقيمته «ملغاة» في ملف التعريف المفحوص. لا يُحوّل «مستورد» إلى «جديدة».
