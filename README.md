# ROJBEY CRM

**نطاق العمل الحالي: [Phase 01 — Google Sheets + Apps Script](phase01/README.md).** الحزمة في `phase01/` منفصلة عن عرض Next.js أدناه. التشغيل الحي على Google لم يُتحقق بعد؛ راجعي [التدقيق والحالة](phase01/docs/TEST_REPORT.md).

نسخة MVP مخصصة لفريق أتيليه Rojbey، باستخدام Next.js وTypeScript وواجهة عربية RTL. الهوية مأخوذة من ملفات Rojbey المرفقة: Pearl / Night / Gold، وخطّا IBM Plex Sans Arabic وCormorant Garamond محفوظان ضمن التطبيق دون طلبات Google Fonts خارجية. حرف R داخل الماسة علامة مؤقتة، وليس الشعار الأصلي.

## التشغيل المحلي

يتطلب Node.js 24+ وnpm. من داخل `/workspace/CRM-Rojbey`:

```bash
npm ci
npm run demo:setup
npm run dev
```

`demo:setup` ينشئ `.env.local` بمفتاح جلسة عشوائي، وصلاحيات ملف 600، ولا يستبدل ملفًا موجودًا. يحفظ التطبيق بيانات وهمية في `.data/crm.json`، وتستمر بعد إعادة التحميل وإعادة تشغيل الخادم. لتجربة الحسابين، اختاري المديرة أو الفريق في شاشة الدخول. هذا الاختيار مفتوح فقط في الوضع التجريبي.

```bash
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run test:production
npm start
```

اختبارات المتصفح تستخدم Chromium المثبت في `/usr/bin/chromium`؛ يمكن تغيير موقعه بمتغير `CHROMIUM_PATH`. تنشئ الاختبارات بيانات مستقلة في مجلد مؤقت ولا تلمس بيانات التشغيل. `npm start` يحتاج ناتج `npm run build`. الخادم مربوط بالواجهة المحلية افتراضيًا.

## المنفّذ

- Dashboard بعدد العميلات والاستفسارات الجديدة ومواعيد اليوم والمتابعات المستحقة، بتوقيت القاهرة.
- بحث بالاسم والموبايل واسم المستخدم، وفلترة بالحالة والقناة، وقائمة الاستفسارات الجديدة.
- إضافة عميلة وملف يشمل القناة والهاتف واسم المستخدم وMeta Contact ID وآخر رسالة والملاحظات والخدمة وقصة الفستان والمسؤولة.
- حجز وتعديل وإلغاء المواعيد، مع منع تداخل وقت الموظفة أو العميلة، وليس تطابق وقت البداية فقط.
- إضافة المتابعات وإكمالها وسجل نشاط مرتبط بكل عميلة.
- دور المديرة يعدّل ملفات العميلات؛ دور الفريق يعرضها ويضيف عميلات ومواعيد ومتابعات. التحقق على API أيضًا.
- جلسات موقعة، cookies من نوع HttpOnly/SameSite، تحقق Origin لعمليات الكتابة، وحد أساسي لمحاولات تسجيل الدخول.
- تطبيع الأرقام العربية ومنع تكرار الموبايل، ومعالجة عرض النصوص بواسطة React.

## الحسابات والإعدادات

راجعي `.env.example`. لا ترفعي `.env.local` أو `.data` إلى GitHub.

| المتغير | الغرض |
| --- | --- |
| `CRM_DATA_PROVIDER` | `local` للعرض أو `sheets` للجسر الموقّع؛ لا رجوع صامت للبيانات المحلية |
| `CRM_DEMO_MODE` | `true` يسمح بدخول تجريبي دون كلمة مرور؛ الافتراضي true في التطوير وfalse في الإنتاج |
| `CRM_SESSION_SECRET` | مفتاح خاص عشوائي بطول 32 حرفًا على الأقل، مطلوب في الإنتاج |
| `CRM_ADMIN_PASSWORD` | كلمة مرور حساب المديرة عند تعطيل الوضع التجريبي |
| `CRM_STAFF_PASSWORD` | كلمة مرور حساب الفريق عند تعطيل الوضع التجريبي |
| `CRM_APP_ORIGIN` | العنوان الخارجي الدقيق عند النشر خلف reverse proxy، مثل `https://crm.example.com`؛ يُستخدم لفحص Origin |
| `CRM_DATA_DIR` | مجلد بيانات محلي بديل؛ يُستخدم لعزل بيانات الاختبارات |

لتجربة الدخول بكلمات مرور، اضبطي `CRM_DEMO_MODE=false` والكلمات والمفتاح في إعدادات آمنة، ثم أعيدي تشغيل الخادم. لا توجد كلمات مرور افتراضية. يستخدم إصدار MVP حسابين وظيفيين مشتركين؛ إدارة موظفات بحسابات فردية، استعادة كلمات المرور وMFA غير منفذة. حد محاولات الدخول في الذاكرة وخاص بعملية الخادم الحالية؛ ليس بديلًا عن حماية مزود الهوية.

## Google Sheets والبيانات الحالية

**لم يُنفّذ اتصال حي بـGoogle Sheets في هذا الإصدار، ولم تتم قراءة أو كتابة أو استيراد أي بيانات حقيقية.** الملفات المرجعية تتضمن Apps Script تاريخيًا، ووجوده لا يثبت نشره أو سلامة مخطط الشيت الحالي. لا تشغّلي `RB_setup` أو تستوردي workbook على الشيت الحالي دون نسخة احتياطية وفحص الأعمدة.

الموفر المحلي يستخدم `CrmRepository`، أما موفر Sheets فيرسل أوامر محددة إلى Apps Script ليحافظ على القفل والتدقيق وفحص الأعمدة هناك. لا يرسل كامل dataset لاستبداله. راجع [دليل Render والشيت](docs/RENDER_SHEETS.md) بدل خطوات الربط القديمة.

## النشر وحدود MVP

`npm run build` ثم `npm start` يشغّل النسخة المبنية. يحتاج مخزن JSON قرصًا دائمًا وعملية خادم واحدة؛ **لا يصلح التخزين المحلي لـserverless أو عدة replicas**. خذي نسخة احتياطية من `.data` قبل التحديث. لا تحذفي الملف إلا لمسح بيانات تجربة مقصود.

يمكن نشر عرض تجريبي بالبيانات الوهمية فقط بعد ضبط `CRM_DEMO_MODE=true` ومفتاح الجلسة؛ أي زائر سيستطيع اختيار دور المديرة. لا تضعي بيانات حقيقية في هذا الوضع. للاستخدام الفعلي يلزم HTTPS، حسابات موظفات فردية، مصدر بيانات حي مختبر، مراجعة صلاحيات وحماية ونسخ احتياطي، وإيقاف demo. متغيرا كلمة المرور يسمحان باختبار صلاحيات MVP داخليًا، ولا يجعلان النظام جاهزًا للإنتاج.

مراجع `docs/skills` و`docs/ROJBEY_CRM_MASTER_SKILL.md` توثّق الهوية وتاريخ المشروع. الادعاءات التاريخية عن 1,465 سجلًا أو ملفات أخرى ليست بيانات موجودة أو عمليات تم التحقق منها في التطبيق الجديد. ملفات العرض وDOCX الأصلية محفوظة في `/workspace/rojbey-resources` خارج checkout.
