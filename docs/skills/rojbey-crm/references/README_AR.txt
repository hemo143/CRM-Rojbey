ROJBEY CRM — COMPLETE PROJECT PACKAGE
حزمة مشروع CRM الخاصة بـ ROJBEY

الغرض
هذه الحزمة تجمع الملفات التي تم إنشاؤها أو حفظها لمشروع ROJBEY Bridal CRM، بما فيها نموذج Google Sheets/Apps Script، ملفات العرض التجريبي، العروض التقديمية، شعار البراند، ومرجع تكامل Meta.

محتويات الحزمة
01_Google_Sheets_and_Apps_Script/
- ROJBEY_CRM_Google_Sheets_Import.xlsx: ملف الاستيراد/البيانات الأولية لـ Google Sheets.
- Code.gs: كود Google Apps Script المرفق بنموذج Phase 01.

02_CRM_Demos/
- ROJBEY_Interactive_CRM_Demo.html: نموذج تفاعلي أولي للـ CRM.
- ROJBEY_Private_Live_CRM_Demo_V2.html: نسخة العرض التجريبي V2.

03_Presentations/
- ROJBEY_CRM_Executive_Presentation_V2.pptx: العرض التنفيذي/خطة المرحلتين.
- ROJBEY_Bridal_CRM_Client_Presentation.pptx: عرض CRM الخاص بـ ROJBEY Bridal.

04_Brand_Assets/
- شعار ROJBEY المستخدم في ملفات المشروع.

05_Original_POC_Kit/
- ROJBEY_CRM_Phase01_Live_POC_Kit.zip: حزمة POC الأصلية، وتتضمن HTML وCode.gs وREADME وملف XLSX والشعار.

06_Meta_Integration/
- ROJBEY_CRM_Skills_Meta_Integration.docx: مرجع إعدادات Meta والخطوات التالية.

ملخص ما تم تصميمه/تخطيطه
- Phase 01: Google Sheets Automation / Live Proof of Concept.
- Phase 02: Cloud CRM / Mobile App كمرحلة لاحقة.
- النموذج الأولي تضمّن بحسب سجل المشروع: 1,465 سجلًا، البحث والفلاتر، إضافة عميلة، حجز مواعيد مع فحص التعارض، المتابعات، ولوحة Dashboard.
- تشغيل التكامل الحقيقي يتطلب نشر Google Apps Script وربطه بملف Google Sheets الفعلي؛ وجود ملفات العرض وحده لا يعني أن النظام منشور أو متصل.
- ربط Instagram/Facebook كان مؤجلًا إلى حين استكمال إعداد Meta والاختبارات.
- التفضيلات المسجلة: واجهة عربية RTL وهوية ROJBEY، مع قوائم منسدلة لمصدر العميلة، الخدمة، الحالة، الموظفة، الموعد، الفستان، الدفع والمتابعة. موديلات الفساتين المذكورة: A-Line, Mermaid, Princess, Satin.

أمان مهم
- لا توجد Tokens أو App Secrets داخل هذه الحزمة.
- ظهر Page Access Token في لقطة شاشة سابقة؛ يجب إلغاء ذلك التوكن وإنشاء بديل قبل الاستخدام.
- لا تضع أي Tokens أو App Secrets داخل ملفات Skills أو مستندات عادية.
- لا تعتبر أي ملف Demo أو POC نظامًا منشورًا أو متصلًا فعليًا حتى يتم اختباره على الحسابات الحقيقية.

ما لم يتم تأكيده بعد
- نشر Apps Script وربطه بملف Google Sheets الحقيقي.
- نجاح تدفق بيانات العملاء في البيئة الفعلية.
- إعداد Webhooks واختبار استقبال الرسائل.
- ربط Facebook/Instagram بالـ CRM بصورة إنتاجية.
- اجتياز مراجعة Meta أو التحقق التجاري أو منح Advanced Access.
